## e2e suite (`build_scripts/verify/e2e/run.py`)

`python3 build_scripts/verify/e2e/run.py` serves the repo on 8767 (or `--base http://127.0.0.1:8765` for a running server, `--only a,b` for some journeys). The ping is routed to a stub and counted, episode audio is a generated 12 s WAV (headless Chromium has no MP3), fonts are stubbed. Journeys: onboarding (double taps, refresh mid-way, exactly one two-field ping, redo prefill), placement (records, focus), drill miss logging (live region, focus, errlog at once, cause patch), timed passage modules (Reading and Science grouping, panel kept, resume, SAT unchanged), podcast (scrub stays locked, suspended-page playback counts, 90% unlock, 3-question check), Settings dark mode (unsaved hint, theme applied, contrast), weekly plan in test week, cross-test deep links, corrupt storage plus milestone toggle, flashcard name and tap targets, true offline 404.
